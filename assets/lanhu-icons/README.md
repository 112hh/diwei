# Lanhu Icon Assets

This folder is reserved for icons exported or cut from the Lanhu UI project.

Rules:

- Add only assets that came from the Lanhu design boards or an already approved
  project asset.
- Register every asset in `manifest.json`.
- Record the source board, export date, dimensions, and intended usage.
- Do not add emoji, text abbreviations, guessed SVG paths, or a second icon
  family.
- Until a board asset is available, keep the slot empty rather than inventing a
  replacement.
